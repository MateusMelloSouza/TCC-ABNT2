\begin{abstract}
Transformer models are expensive to run on edge devices. We propose a sparse
attention kernel for embedded GPUs that skips low-scoring blocks. On a Jetson
board it is 2.1 times faster than dense attention with an accuracy loss below
0.5 points.
\end{abstract}

\begin{IEEEkeywords}
sparse attention, edge computing, GPU kernels
\end{IEEEkeywords}

\section{Introduction}
Attention mechanisms \cite{vaswani2017attention} dominate modern sequence
models, but their cost grows quadratically with the sequence length
\cite{vaswani2017}. In our previous work \cite{doe2024sparse}, we showed that
most attention blocks contribute little to the output. Efficient inference on
embedded GPUs has been studied before \cite{chen2021edge}.

# Publisher classes — verified preambles, citation setup and rules

Every snippet below is a test document in the skill's repository
(`tests/publisher/*.tex`) compiled with TeX Live 2023 (IEEEtran 1.8b, acmart
2.03, elsarticle 3.x, llncs 2.24, REVTeX 4.2f, amsart 2.20.6). Always prefer the
venue's **current** template and author instructions — they may set options,
page limits and rights blocks that differ from these generic forms.

Common rules for all of them: do not change fonts, margins, spacing or caption
styles; do not load `geometry`, `times`, `setspace` or `titlesec`; no negative
`\vspace` hacks; captions above tables and below figures unless the class does
otherwise; use the class's bibliography style.

## 1. IEEEtran

```latex
\documentclass[conference]{IEEEtran}   % journals: [journal]; Computer Society: [conference,compsoc] / [journal,compsoc]
\IEEEoverridecommandlockouts          % lets \thanks work in conference mode
\usepackage{cite}                     % sorts and compresses: [1]-[3]
\usepackage{amsmath,amssymb}
\usepackage{graphicx}
\begin{document}
\title{Paper Title\thanks{Funding acknowledgement.}}
\author{\IEEEauthorblockN{First Author}
\IEEEauthorblockA{\textit{Department} \\ \textit{University}\\ City, Country \\ first@example.org}
\and
\IEEEauthorblockN{Second Author}
\IEEEauthorblockA{\textit{Institute} \\ City, Country \\ second@example.org}}
\maketitle
\begin{abstract} … \end{abstract}
\begin{IEEEkeywords} first keyword, second keyword \end{IEEEkeywords}
\section{Introduction}
… \cite{knuth1984literate} …
\bibliographystyle{IEEEtran}
\bibliography{refs}                   % journal abbreviations: \bibliography{IEEEabrv,refs}
\end{document}
```
- Journal mode: authors as `First~Author,~\IEEEmembership{Member,~IEEE,}`
  with affiliations in `\thanks{}`; running heads via `\markboth{…}{…}`; the
  first word with `\IEEEPARstart{T}{his}`. Review copies: `[journal,peerreview]`
  (journal layout plus a single-column cover page with title and authors).
- Tables are captioned above as "TABLE I" (roman numerals) by the class;
  figures below as "Fig. 1".
- Citations: numeric in order of citation; `\cite{a,b,c}` with the `cite`
  package → "[1]–[3]". IEEEtran.bst handles IEEE's name and title rules; brace
  acronyms in titles (`{GPU}`) because it changes case.
- Camera-ready copyright notice: the conference gives the text and the
  command (often `\IEEEpubid{…}`); fonts must be embedded (IEEE PDF eXpress).
- Many IEEE conferences are double-blind but IEEEtran has no anonymous option:
  replace the author block with "Anonymous Authors" as the call instructs.

## 2. acmart

```latex
\documentclass[sigconf]{acmart}       % review copy: [sigconf,review,anonymous]; journals: [acmsmall] / [acmlarge] / [acmtog]
\setcopyright{acmlicensed}            % these rights lines come from the ACM rights form at camera-ready
\copyrightyear{2026}
\acmYear{2026}
\acmDOI{XXXXXXX.XXXXXXX}
\acmConference[Conf '26]{Conference Name}{Month dates, 2026}{City, Country}
\acmISBN{978-1-4503-XXXX-X/2026/MM}
\begin{document}
\title{Paper Title}
\author{First Author}
\affiliation{\institution{University}\city{City}\country{Country}}
\email{first@example.org}
\begin{abstract} … \end{abstract}    % BEFORE \maketitle
\begin{CCSXML} … \end{CCSXML}        % generated by the ACM CCS tool (dl.acm.org/ccs)
\ccsdesc[500]{Software and its engineering}
\keywords{first keyword, second keyword}
\maketitle
\section{Introduction}
… \cite{knuth1984literate}; \citet{lamport1994latex} …
\bibliographystyle{ACM-Reference-Format}
\bibliography{refs}
\end{document}
```
- **Abstract, CCS concepts and keywords go before `\maketitle`.**
- Formats: `sigconf`, `sigplan`, `sigchi-a`, `acmsmall`, `acmlarge`, `acmtog`,
  `manuscript`, `acmengage`, `acmcp`; options `review` (line numbers),
  `anonymous` (prints "Anonymous Author(s)" — verified), `authorversion`,
  `screen`, `nonacm` (drops ACM-specific elements for non-ACM uses).
- Citations: natbib is loaded by the class; `ACM-Reference-Format` is numeric
  and supports `\citet`; author-year with `\citestyle{acmauthoryear}`. biblatex
  is possible: `\documentclass[sigconf,natbib=false]{acmart}` +
  `\usepackage[style=acmnumeric]{biblatex}` (or `acmauthoryear`) — these styles
  work only inside acmart (verified).
- Fonts: acmart requires Libertine, newtxmath and Inconsolata (zi4); full TeX
  Live, MiKTeX and Overleaf have them; on Debian/Ubuntu install
  `texlive-fonts-extra` (without it the class warns "You do not have the
  libertine package installed" and fails).
- Check `\acmConference`, rights and DOI lines at camera-ready against the
  rights-form e-mail; ACM's TAPS system re-processes the source — no
  `\vspace` hacks, no custom packages beyond its accepted list.

## 3. elsarticle

```latex
\documentclass[preprint,12pt]{elsarticle}   % final look: [final,5p,times,twocolumn]; double-spaced review: [review]
\usepackage{amsmath}
\journal{Journal Name}
\begin{document}
\begin{frontmatter}
\title{Paper Title}
\author[inst1]{First Author\corref{cor1}}
\ead{first@example.org}
\cortext[cor1]{Corresponding author}
\author[inst2]{Second Author}
\affiliation[inst1]{organization={Department, University}, city={City}, country={Country}}
\affiliation[inst2]{organization={Institute}, city={City}, country={Country}}
\begin{abstract} … \end{abstract}
\begin{keyword} first keyword \sep second keyword \sep third keyword \end{keyword}
\end{frontmatter}
\section{Introduction}
… \cite{knuth1984literate} …
\bibliographystyle{elsarticle-num}
\bibliography{refs}
\end{document}
```
- Everything before the body lives in `frontmatter`; keywords separated by
  `\sep`; the class also defines a `highlights` environment.
- Citation styles: `elsarticle-num` (numeric, **no author data**: `\citet`
  prints "Author?" — verified), `elsarticle-num-names` (numeric with `\citet`
  working: "Lamport [2]"), `elsarticle-harv` with the `authoryear` class
  option (author-year; there plain `\cite` is textual "Knuth (1984)" — use
  `\citep` for parentheses). Each journal's guide says which.
- Options: `preprint`, `review`, `final`, `1p`/`3p`/`5p` (journal page looks),
  `twocolumn`, `authoryear`, `number`.

## 4. llncs

```latex
\documentclass[runningheads]{llncs}
\usepackage{graphicx}
\begin{document}
\title{Paper Title}
\author{First Author\inst{1}\orcidID{0000-0000-0000-0000} \and Second Author\inst{2}}
\authorrunning{F. Author and S. Author}
\institute{University, City, Country \email{first@example.org} \and Institute, City, Country}
\maketitle
\begin{abstract}
…
\keywords{First keyword \and Second keyword \and Third keyword.}
\end{abstract}
\section{Introduction}
… \cite{knuth1984literate} …
\bibliographystyle{splncs04}
\bibliography{refs}
\end{document}
```
- Keywords **inside** the abstract environment, separated by `\and`.
- llncs predefines `theorem`, `lemma`, `definition`, `proof` and friends.
  Loading `amsthm` fails with `Command \proof already defined` — if you need
  amsthm, put `\let\proof\relax \let\endproof\relax` before
  `\usepackage{amsthm}` (verified), or just use llncs's environments.
- Page limits are set by each conference (typically including references);
  do not change the layout to fit — cut text.
- Camera-ready: the conference may require the source files, the copyright
  form and specific ORCID handling.

## 5. REVTeX 4.2

```latex
\documentclass[aps,prl,reprint]{revtex4-2}   % preprint layout: [aps,pra,preprint]; AIP: [aip,jcp]
\begin{document}
\title{Paper Title}
\author{First Author}
\email{first@example.org}
\affiliation{Department, University, City, Country}
\author{Second Author}
\affiliation{Institute, City, Country}
\date{\today}
\begin{abstract} … \end{abstract}    % BEFORE \maketitle
\maketitle
\section{Introduction}
… \cite{knuth1984literate} …
\bibliography{refs}                   % aps selects apsrev4-2.bst: no \bibliographystyle
\end{document}
```
- Options: society `aps`/`aip`, journal (`prl`, `pra`, `prb`, …, `jcp`),
  `reprint`/`preprint`, `superscriptaddress`, `longbibliography` (titles in
  references), `nofootinbib`.
- `\affiliation` follows the authors it applies to; `\email` after the author.
- Physics Subject Headings (PhySH) replaced PACS codes at APS journals.

## 6. amsart

```latex
\documentclass{amsart}
\newtheorem{theorem}{Theorem}[section]
\begin{document}
\title{Paper Title}
\author{First Author}
\address{Department, University, City, Country}
\email{first@example.org}
\subjclass[2020]{Primary 68U15; Secondary 68N15}
\keywords{first keyword, second keyword}
\begin{abstract} … \end{abstract}    % BEFORE \maketitle
\maketitle
\section{Introduction}
… \cite{knuth1984literate} …
\bibliographystyle{amsplain}          % or amsalpha
\bibliography{refs}
\end{document}
```
- AMS classes load amsmath and amsthm themselves; MSC 2020 codes in
  `\subjclass[2020]{…}`.

## 7. Other classes you will meet

In TeX Live: `aastex631` (AAS journals: ApJ, AJ), `mnras` (Monthly Notices of
the RAS), `jmlr` (JMLR/PMLR), `revtex4-1` (older APS/AIP), `achemso` (ACS
journals). Distributed by the publisher or on Overleaf (not in TeX Live):
Springer Nature journals (`sn-jnl`, with `sn-*.bst` styles), Wiley, Taylor &
Francis (`interact`), MDPI, PLOS, Frontiers, Copernicus, IOP, IEEE Access, the
ML/NLP conference styles (NeurIPS, ICML, ICLR, ACL — `.sty` files used with
`article`; they change every year: download the current year's kit). Profile any
of them with `templates/README.md` before writing.
